# WayEcho Working Demo

Đây là bản web demo tương tác, không chỉ là giao diện tĩnh.

## Chạy
Mở `index.html` trực tiếp bằng Chrome/Edge, hoặc upload cả thư mục lên Vercel.

## Các phần đã bấm được
- Trang chủ
- Khám phá
- 6 nhóm dịch vụ: Điểm đến / Lưu trú / Ăn uống / Hoạt động / Vé / Di chuyển
- Bộ lọc thay đổi theo từng nhóm dịch vụ
- Tìm kiếm
- Tìm kiếm bằng giọng nói (nếu trình duyệt hỗ trợ; nếu không sẽ có mô phỏng)
- Đọc nội dung bằng giọng nói
- Accessibility Profile / Nhu cầu của tôi
- Xem chi tiết dịch vụ
- Đặt chỗ
- Gửi yêu cầu hỗ trợ
- Đặt chỗ xuất hiện trong mục Đặt chỗ
- Thêm đặt chỗ vào Chuyến đi của tôi
- Lưu dữ liệu demo bằng localStorage nên refresh trang vẫn còn dữ liệu

## Lưu ý
Đây là prototype frontend. Chưa có backend thật, tài khoản thật, thanh toán thật, bản đồ/GPS thật hay cơ sở dữ liệu doanh nghiệp.
